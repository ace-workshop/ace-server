# 服务端交付边界

| 目标 | 满足条件 |
| --- | --- |
| 单节点多核 Actor | 同实例的回调片段不重叠，不同实例可并行；等待异步调用不堵 mailbox。报告同机负载和延迟条件，不预设 QPS。 |
| 动态实例与 RPC | 仅从启动已装载的库创建／停止实例；地址为高 16 位节点、低 48 位持久流水号。超时、停止、断线不能把一次调用终结两次。 |
| 本地与线上消息 | 独立库间布局兼容的本地请求及响应不调用 codec；其余仅在 wire 契约匹配时走字节路径。验证所有权、限额、释放与真实编解码次数。 |
| 接入与扩展 | TCP 与 KCP 使用同一 Gate 和 Watchdog。三种内置角色均可单独替换，编译期换角色 codec 时无需重建 host。 |
| 部署关闭 | SIGTERM 撤销 ready 和新入口，按配置别名收回接入、业务及控制器；未决任务取消而非保证排空。超过协作期限不报告正常退出，失控 native 不能安全抢占。 |
| 节点扩展 | 运行中的两节点可发现并调用新加入的第三节点。单种子失联不切断健康直连，但暂停新成员加入；不迁移既有 Actor。 |

本轮不交付游戏业务、确定性战斗、原生 UDP 业务接口、浏览器入口、运行时装卸新库或生产认证。网络和动态库必须在 Linux 与 macOS 实际运行；编译依赖骨架不代表上表任何一项已经通过。

实际验证入口见 [README](../README.md)，同机性能对照与局限见[架构](architecture.md#同机测量)。托管 CI 执行确定性行为而不设吞吐／延迟阈值。
